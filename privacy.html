Privacy Policy

myemailmanager · last updated 2026-10-03

myemailmanager is a personal command-line tool used solely by its author. It has no other users, no server component, and no analytics.

Information accessed

With the account owner's explicit consent, the tool accesses Gmail messages and message metadata through the https://mail.google.com/ OAuth scope, over IMAP and SMTP. This access is used only to read mail from, and send mail on behalf of, the account that granted consent.

Storage

OAuth credentials and refresh tokens are stored in a file on the local machine that runs the tool. Message contents are held in memory for the duration of a run, and are written to disk only when the operator explicitly asks the tool to save them. Nothing is uploaded anywhere.

Sharing

No information obtained from Google APIs is transmitted to the author, to any server, or to any third party. Nothing is sold, rented, or used for advertising. No human other than the account owner reads the data.

Limited Use

myemailmanager's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Stored tokens and any saved messages are deleted by removing the tool's local data directory. Revoking the application at myaccount.google.com/permissions immediately invalidates all issued tokens.
